# 🧱 Port Filter Script - Enhanced Version

一键配置服务器端口访问规则，支持国内/国际分流、端口屏蔽放行、IP白名单管理、规则库选择等功能。

当前版本 **v3.2.0**，需要 root 权限运行，适用于 Debian / Ubuntu（依赖通过 apt 自动安装）。

## ✨ 功能

### 🎯 IP白名单管理
- ✅ 支持单个IP地址和IP段
- ✅ 白名单IP不会被本脚本设置的规则拦截
- ✅ 动态添加/删除白名单IP
- ✅ 命令行快速添加

### 🛠 IP 源规则库选择
- ✅ 内置 3 个中国IP数据源，默认全部启用（合并后的列表更完整）
- ✅ 可按需启用/禁用某个数据源
- ✅ 变更在下次更新中国IP列表时生效

### 🔒 安全保护
- ✅ 通过 SSH 管理服务器时，拦截 SSH 端口前会提醒先把当前管理IP加入白名单，防止把自己锁在外面
- ✅ 下载中国IP列表失败时保留正在使用的列表，不会让规则“失效”或“误拦”
- ✅ 清除规则时只删除本脚本添加的规则，不影响其它程序
- ✅ 端口、IP 格式不正确时直接提示，不会写入配置

## ✨ 原有功能
- ✅ 国内/国际 IP 地域过滤（黑名单、白名单）
- ✅ 一键屏蔽或放行指定端口（支持 TCP / UDP / 双协议，支持端口范围如 `8000:9000`）
- ✅ 多源中国 IP 列表聚合导入，规则更全面
- ✅ 支持计划任务，自动定时更新 IP 数据
- ✅ 彩色交互菜单，SSH 终端友好
- ✅ iptables/ipset 规则持久化保存，重启后自动恢复

### IP白名单管理
- **添加白名单**: 输入单个IP（192.168.1.100）或IP段（10.0.0.0/8）
- **优先级**: 白名单IP不会被本脚本设置的过滤规则拦截
- **动态生效**: 添加后立即生效，无需重启
- **生效范围**: 只对本脚本设置过策略的端口生效

### IP 源规则库选择
- **数据源**: 内置 `metowolf/IPList`、`17mon/ChinaIPList`、`gaoyifan/OperatorIP` 三个中国IP数据源
- **合并使用**: 启用的数据源会合并成一份中国IP列表，默认全部启用；启用得越多，国内IP列表越完整
- **动态切换**: 可随时启用或禁用，在下次更新中国IP列表（菜单 8 或定时更新）时生效

## 🚀 安装

### 一键安装（推荐）
```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/wxhdrsa7/port-filter-script/main/install.sh)
```

### 手动安装
```bash
curl -fsSL https://raw.githubusercontent.com/wxhdrsa7/port-filter-script/main/port-filter.sh -o /usr/local/bin/port-filter
chmod +x /usr/local/bin/port-filter
sudo port-filter
```

## 💻 使用方法

### 启动交互式菜单
```bash
sudo port-filter
```

### 命令行
```bash
# 添加单个IP到白名单
sudo port-filter --whitelist 192.168.1.100

# 添加IP段
sudo port-filter --whitelist 10.0.0.0/8

# 立即更新中国IP列表（定时任务执行的也是这条命令）
sudo port-filter --update-ip

# 查看帮助和版本
port-filter --help
port-filter --version
```

## 📋 使用示例

> 做任何“拦截”类设置之前，先把你的管理IP加入白名单，避免把自己挡在外面。

### 场景1：允许内网和管理IP访问
```bash
# 先把内网段和管理IP加入白名单
sudo port-filter --whitelist 192.168.0.0/16
sudo port-filter --whitelist 203.0.113.100
```

### 场景2：网站只允许国内访问
```bash
sudo port-filter
# 选择菜单 1（IP 地域过滤）
# 端口：443    协议：1（TCP）    模式：2（白名单，仅允许中国IP）
```

### 场景3：屏蔽某个端口（白名单IP仍可访问）
```bash
sudo port-filter
# 选择菜单 2（屏蔽端口），输入端口并选择协议
```

### 场景4：阻止国内IP访问某个端口
```bash
sudo port-filter
# 选择菜单 1（IP 地域过滤），模式选 1（黑名单，阻止中国IP）
```

## ⚠️ 注意事项

1. **白名单优先**: 添加到白名单的IP不会被本脚本设置的规则拦截
2. **先加白名单**: 做“屏蔽端口”或“仅允许中国IP”之前，先把自己的管理IP加入白名单
3. **IP格式**: 支持单个IP（192.168.1.100）和IP段（10.0.0.0/8）；IP段要写成网络地址，例如 `10.1.2.0/24` 而不是 `10.1.2.3/24`；只支持 IPv4
4. **端口范围**: 单个端口写 `443`，连续的多个端口写 `8000:9000`
5. **权限要求**: 需要root权限运行
6. **仅 IPv4**: 本脚本只管理 IPv4 规则；服务器如果启用了 IPv6，IPv6 的访问不受影响，需要另行处理
7. **数据源**: 中国IP列表来自 GitHub 上的开源数据源，服务器需要能访问 `raw.githubusercontent.com`；下载失败时会继续使用现有的列表
8. **备份建议**: 修改配置前建议备份重要数据

## 🧹 卸载

先在菜单里清除本脚本添加的规则（菜单 7），再删除文件：

```bash
sudo port-filter            # 选择 7「清除所有规则」，需要输入 y 确认
sudo rm -f /usr/local/bin/port-filter
sudo rm -rf /etc/port-filter /var/log/port-filter
```

请不要用 `iptables -F INPUT` 来卸载：它会连其它程序（如 Docker）添加的规则一起清空。

## 🔧 故障排除

### 规则不生效
- 检查是否使用了root权限
- 确认iptables服务正在运行
- 查看是否有其他防火墙规则冲突

### 重启后规则丢失
- 规则和 ipset 集合由 `iptables-persistent` 和 `ipset-persistent` 负责保存和恢复，脚本会自动安装；如果提示安装失败，请手动执行 `apt-get install iptables-persistent ipset-persistent`

### 白名单无效
- 检查IP格式是否正确
- 确认IP是否已添加到白名单文件（`/etc/port-filter/whitelist.conf`）
- 白名单只对本脚本设置过策略的端口生效
- 用 `sudo ipset list whitelist` 查看已生效的白名单

### 中国IP列表更新失败
- 检查服务器能否访问 `raw.githubusercontent.com`
- 更新失败时现有的列表不会被改动，已有规则继续有效
- 可以在菜单 6 里更换启用的数据源

### 误拦截问题
- 把需要放行的IP加入白名单
- 确认模式选择正确：黑名单是“阻止中国IP”，白名单是“只允许中国IP”

## 📝 v3.2.0 更新内容

- 修复“仅允许中国IP”模式的规则顺序错误（旧版本实际会把所有来源都拦截）

- 下载中国IP列表失败不再被当成成功，也不会再把正在使用的列表清空

- 修复“从白名单移除IP段”和“禁用IP数据源”提示成功但没有生效的问题
- 端口和IP输入校验；策略文件不再产生重复记录
- 修复 ipset 集合没有被持久化、重启后规则恢复失败的问题
- 输入流关闭（Ctrl+D）时不再死循环；保存失败、命令执行失败时如实提示
- 新增 `--help`、`--version`；`--whitelist`、`--update-ip` 在失败时返回非 0
